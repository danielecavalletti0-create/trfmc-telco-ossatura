Change Control

Blocco operativo

NO MASS PATCH

Ogni modifica deve avere snapshot, hash, quality gate, rollback path.

Policy operativa

Procedura ammessa

  1. Definire una sola pagina o un solo dominio.
  2. Snapshot prima della modifica.
  3. Modifica scoped.
  4. HTTP gate.
  5. External/iframe gate.
  6. Hash V6R3 e Control Room invariati.
  7. Nuovo freeze se PASS.

Divieti

Vietati iframe, CDN, patch massive, doppie barre, shell parallele, modifica diretta di V6R3 senza change request.
